# 丑团 · 送啥都快

> 一个伪装成购物 App 的情绪化消费觉察工具。
> 前台完全对标美团外卖，价值后置到每周的消费周报。

## 这是什么

很多人在深夜情绪低落时冲动下单，其实并不真的需要那件商品，只是想用「下单」这个动作缓解压力。

丑团用一套和真实外卖 App 一样顺滑的购物体验承接这种冲动——店铺流、菜单、购物车、下单、骑手配送、确认收货，全链路真实可信；再通过每周的**消费周报**让用户自己看见消费习惯：下单金额、笔数、时段分布、深夜下单提示、以及"收藏了却没下单"的克制正反馈。不说教、不评判。

## 快速开始

纯静态、零构建，直接用浏览器打开即可：

```bash
# 方式一：直接打开
open index.html

# 方式二：本地服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 功能一览

- **购物前台**（对标美团外卖）
  - 店铺流首页 + 分类筛选 + 限时秒杀（距当日 24:00 真实倒计时）
  - 店铺详情页：店招 / 评分 / 月售 / 公告 / 左右分栏菜单 / 实时结算条（差 X 元起送）
  - 商品详情：券后价 + 原价划线 + 满减标签 + 用户评价区
  - 搜索：按名称 / 描述 / 分类 / 标签 / 店铺名 / 品牌匹配，含搜索历史与热门词
  - ❤️ 收藏 / 心愿单
  - 购物车：跨店按店铺分组、分别小计、就地步进器
  - 下单结算：收货地址 / 配送时段 / 备注 / 支付方式 / 自动计算"已优惠"
  - 物流追踪：五阶段推进 + 骑手卡 + 预计送达倒计时（演示加速：每 15 秒一阶段）
  - 订单管理：确认收货 / 订单详情 / 再来一单
- **觉察后台**
  - 消费周报：本周金额、笔数、累计消费
  - 时段洞察：深夜 / 上午 / 下午 / 晚间下单分布
  - 深夜下单温和提示 + 缓冲建议（"先放一放，睡一觉再决定"）
  - 克制正反馈：收藏了却没下单 = 被你稳稳接住的冲动

## 技术架构

HTML + CSS + 原生 JS，四层结构：

```
index.html          入口
css/style.css       美团风移动端样式（480px 容器）
js/data.js          数据层：16 家店铺 / 64 款商品 / 评价语料
js/state.js         状态层：购物车 / 订单 / 收藏 / 周报统计（localStorage 持久化）
js/views.js         渲染层：纯函数，返回 HTML 字符串
js/app.js           控制层：hash 路由 / 事件委托 / 定时刷新
img/                真实产品照片（64 商品 + 16 店招）+ 分类图标
tools/              照片素材拉取 / 裁切处理 / 分类图标生成脚本
```

- 数据存浏览器 `localStorage`，刷新不丢；换浏览器或清缓存即重置。
- 门店均为现实品牌的搞笑化名（麦当当、啃德鸡、必胜胜客、海底捞捞……），纯属虚构。
- **商品图与店招均为真实食物照片**，取自以下开源模板/图库仓库
  （经 Go module proxy 拉取，来源与许可见 `tools/fetch-photos.sh`）：
  [Foodish](https://github.com/surhud004/Foodish)（MIT）、
  codewithsadee 的 [grilli](https://github.com/codewithsadee/grilli) / [foodie](https://github.com/codewithsadee/foodie)（MIT）、
  themewagon 的 feane / feliciano（CC BY 3.0）、
  gethugothemes 的 restaurant-hugo（MIT）。
  复现流程：`tools/fetch-photos.sh` 拉素材 → `tools/prepare-photos.js` 按
  `tools/photo-map.json` 裁切出 `img/*.webp`。
- 演示加速：配送每 15 秒推进一阶段（`js/state.js` 中的 `STEP_MS`），约 1 分钟走完全程。
