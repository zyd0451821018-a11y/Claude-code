# 丑团 — 打包部署流程

> 参考 [驭流-打包部署流程] 的范式整理。v2 起带轻后台：FastAPI + SQLite（管理后台
> `/admin` 在线改商品价格/售罄 + 访问/下单统计），前端购物数据仍在访问者浏览器
> localStorage。后台不可达时前端自动回退内置数据，双击 index.html 依然完整可用。

## 环境说明

- 本地开发：Mac（arm64）
- 服务器：`Liyibin@8.141.121.22`，Linux/amd64
- 服务端口：**`9000`**（映射容器内 `80`）—— ⚠️ `8011` 驭流、`8012` 作图工作台已占用，勿重合
- 域名：`www.choutuan.cloudwaveai.cn`（兼收 `choutuan.cloudwaveai.cn`）
- 镜像名：`choutuan-api:latest`，容器名：`choutuan-web-1`，compose 服务名：**`web`**
- 架构：**单容器**（`python:3.11-slim`，FastAPI 托管 API + 前端静态产物，同源）

## 一、本地打包

```bash
cd <仓库目录>/choutuan   # git clone 后的 choutuan 子目录

DOCKER_BUILDKIT=1 docker buildx build \
  --platform linux/amd64 \
  -f Dockerfile.prod \
  -t choutuan-api:latest \
  --load \
  .
```

> - `--load` 必须加，否则镜像不写入本地 Docker daemon。
> - 前端零构建，Dockerfile 只做 pip install + COPY；后端仅 fastapi + uvicorn 两个依赖。
> - 镜像约 **180MB**（python:3.11-slim ~130MB + 依赖 + 站点 18MB）。
> - 若拉 `python:3.11-slim` 报镜像源抖动，先 `docker pull --platform linux/amd64 python:3.11-slim`
>   单独拉一次再构建。

------

## 二、导出镜像

```bash
docker save choutuan-api:latest | gzip > /tmp/choutuan-api.tar.gz
```

约 **80MB**。

------

## 三、上传到服务器

```bash
sshpass -p '<服务器密码>' scp -o StrictHostKeyChecking=no \
  /tmp/choutuan-api.tar.gz Liyibin@8.141.121.22:/tmp/choutuan-api.tar.gz
```

------

## 四、服务器准备（首次部署）

```bash
ssh Liyibin@8.141.121.22
sudo mkdir -p /opt/choutuan
# 把 docker-compose.prod.yml 和 .env 放到 /opt/choutuan/
```

`.env`（含管理后台密码，不入镜像，用 env_file 注入）：

```
ADMIN_PASSWORD=<自定义强密码>
```

> ⚠️ 不配 .env 时后台默认密码为 `choutuan123`，公网环境务必修改。

> ⚠️ 端口在 `docker-compose.prod.yml` 里是 `9000:80`，先确认服务器 9000 未被占用：
> `sudo lsof -i :9000` 应为空。

------

## 五、加载镜像并重建容器

```bash
sudo docker load -i /tmp/choutuan-api.tar.gz

cd /opt/choutuan
sudo docker compose -f docker-compose.prod.yml up -d --no-deps web

sleep 3
```

> **关键坑（同驭流）**：换镜像必须 `docker compose ... up -d` 重建容器，
> `docker restart` 只会继续跑旧镜像。compose 里**服务名是 `web`**，容器名是 `choutuan-web-1`。
> 验证镜像确实换了：
>
> ```bash
> sudo docker inspect choutuan-web-1 --format '{{.Image}}'
> sudo docker images choutuan-api:latest --format '{{.ID}}'
> ```

## 六、数据持久化

后台数据走 **docker volume**，换镜像不丢：

| 数据                          | 位置                 | 持久化方式                    |
| ----------------------------- | -------------------- | ----------------------------- |
| 商品覆盖项（改价/售罄）       | 容器 `/app/db`       | volume `choutuan_db`（SQLite）|
| 访问/下单统计                 | 容器 `/app/db`       | 同上                          |
| 购物车 / 订单 / 收藏 / 周报  | 访问者浏览器         | `localStorage`（用户侧自持）  |
| 站点文件                      | 镜像内（只读）       | 随镜像发版                    |

> 无迁移框架：启动时 `CREATE TABLE IF NOT EXISTS` 自动建表（仅新增表，不改旧表）。

## 域名与 Nginx（首次部署）

1. **DNS**：在 `cloudwaveai.cn` 的解析里加两条 A 记录 → `8.141.121.22`：
   `www.choutuan` 与 `choutuan`。

2. **宿主机 Nginx**：把仓库里 `deploy/nginx-host-choutuan.conf` 放到服务器：

   ```bash
   sudo cp nginx-host-choutuan.conf /etc/nginx/conf.d/choutuan.conf
   sudo nginx -t && sudo systemctl reload nginx
   ```

   server 块反代到 `127.0.0.1:9000`，与驭流/作图工作台的规范一致。

3. **HTTPS 证书**：

   ```bash
   sudo certbot --nginx -d www.choutuan.cloudwaveai.cn
   ```

   > ⚠️ **只签有 DNS 记录的域名**。certbot 签发是全有或全无：只要命令里
   > 有一个域名解析不存在（如未加 A 记录的裸域 `choutuan.cloudwaveai.cn`），
   > 整张证书都会签发失败 → 443 上没有本站块 → https 请求落入其他项目的
   > 默认 443 块 → 浏览器报 HTTP 500"目前无法处理此请求"。
   > 若要裸域也可访问，先加 A 记录、`dig` 确认生效，再把 `-d choutuan.cloudwaveai.cn` 加回来。

4. **验收**：浏览器打开 <https://www.choutuan.cloudwaveai.cn> ——
   首页 40 家店铺流可滑动、进店加购、下单后骑手配送每 15 秒推进一阶段。
